공개 API 문서

개요

이 결제 API는 가맹점이 안전하게 결제를 처리할 수 있도록 결제 생성, 조회, 취소 기능을 제공합니다.

API를 통해 인증 및 결제 관련 작업을 수행할 수 있으며, 결제를 통한 거래 내역 조회, 출금 신청, 정산 확인 등은 가맹점 페이지에서 상세히 확인할 수 있습니다.

본 문서는 가맹점 개발자를 대상으로 작성되었으며, API 연동을 위한 가이드와 사용 예시를 제공합니다.

가이드

1. 연동 준비

API 키 생성

데키나 결제 API를 사용하려면 먼저 API 키를 발급받아야 합니다.

발급된 API 키는 클라이언트(가맹점)의 요청을 인증하고 권한을 확인하는 용도로 사용되며, 이를 통해 결제 관련 작업을 수행할 수 있습니다.

API 키 종류

결제 API에는 두 가지 키가 존재합니다:

키 종류 용도
client 일반적인 서비스 이용 시 사용자 인증 및 권한 확인에 사용
secret 결제, 결제 취소(환불) 등 민감한 작업 시 사용. 외부 노출 금지

⚠ 주의: secret 키는 절대 클라이언트에 노출되지 않도록 서버에서 안전하게 관리해야 합니다.

2. 연동

결제·결제 취소(환불) API를 호출할 때에는 발급받은 API 키(client, secret)를 포함하여 요청합니다.
각 API의 상세 사용 방법은 결제·결제 취소(환불) API 문서를 참고하세요.

API 키 발급

API 키를 발급하는 API 입니다.

세션이 생성된 상태에서 호출할 수 있는 API로 로그인 후 해당 API 호출이 가능합니다.

발급된 키 중 'client' 키는 일반적인 서비스 이용 시에 대한 사용자의 인증과 권한 확인 등에 사용됩니다. 발급된 키 중 'secret' 키는 결제 서비스 등 민감한 서비스 이용 시에 대한 사용자의 인증과 권한 확인 등에 사용됩니다.

이 키는 외부에 노출되지 않도록 특별히 주의하여 보관해야 하며, 외부 노출 시 즉시 재발급받아야 합니다.

  • 401 : 인증 실패

결제

카드 결제를 수행하는 API 입니다.
